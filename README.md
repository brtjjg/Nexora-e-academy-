# Nexora Academy 🎓

Expert online learning platform — Learn. Grow. Achieve.

🌐 **Live:** https://nexora-e-academy.vercel.app

## Features
- 📚 Expert-led online courses
- 💳 Flexible installment payments (Lipa Mdogo Mdogo)

- 💬 Group discussions & community chat
- 📊 Student dashboard with progress tracking
- 🔐 Admin portal for course & student management

## Tech Stack
- Frontend: HTML, CSS, JavaScript (SPA)
- Backend: Node.js (server.js)
- Database: PostgreSQL
- Hosting: Vercel
